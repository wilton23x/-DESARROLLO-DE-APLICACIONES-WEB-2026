📘 Acerca de este sitio web

Biblioteca Virtual es una aplicación web desarrollada con el framework Flask, diseñada para gestionar libros de manera sencilla y organizada.

Este sitio permite visualizar libros registrados, agregar nuevos libros y navegar entre diferentes secciones como Inicio, Contactos y Productos. Todo esto utilizando una estructura basada en rutas y plantillas dinámicas.

El proyecto fue desarrollado aplicando tecnologías como:

  • HTML para la estructura
  • CSS para el diseño personalizado
  • Bootstrap para el diseño responsivo
  • Flask como backend en Python
  • Jinja2 para la herencia de plantillas

El objetivo principal de este sitio es demostrar la integración entre frontend y backend en una aplicación web funcional.
