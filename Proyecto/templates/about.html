📘 Acerca del Sistema

Biblioteca Virtual Express es un Sistema Avanzado de Gestión de Inventario desarrollado con el framework Flask en Python. Su propósito es administrar libros de manera organizada, permitiendo registrar, editar, eliminar y visualizar información almacenada en una base de datos.

La aplicación implementa el modelo CRUD (Crear, Leer, Actualizar y Eliminar), conectado a una base de datos SQLite para garantizar el almacenamiento persistente de los datos.

Además, el sistema fue desarrollado aplicando Programación Orientada a Objetos (POO), utilizando clases como Producto e Inventario, junto con colecciones de Python como diccionarios y listas para gestionar eficientemente la información.

🔧 Tecnologías utilizadas:
  • HTML5 para la estructura del contenido
  • CSS3 para estilos personalizados
  • Bootstrap 5 para diseño responsivo
  • Flask como framework backend en Python
  • SQLite como base de datos
  • Jinja2 para la herencia de plantillas dinámicas

Este proyecto fue desarrollado como parte de la asignatura Desarrollo de Aplicaciones Web en la Universidad Estatal Amazónica, con el objetivo de integrar frontend y backend en una aplicación web funcional.
