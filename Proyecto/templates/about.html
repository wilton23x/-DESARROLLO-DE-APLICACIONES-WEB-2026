📘 Acerca del Sistema

Información general del proyecto Biblioteca Virtual Express

Biblioteca Virtual Express es un sistema web de gestión de inventario desarrollado con Flask (Python), diseñado para administrar de forma eficiente el registro de libros dentro de una biblioteca digital.

El sistema permite realizar operaciones fundamentales sobre los registros de libros mediante el modelo CRUD (Crear, Leer, Actualizar y Eliminar), permitiendo gestionar información como:

  • Registro de nuevos libros
  • Visualización del inventario
  • Edición de información
  • Eliminación de registros
  • Búsqueda de libros dentro del sistema

La aplicación se conecta a una base de datos SQLite, lo que permite almacenar los datos de forma persistente y segura.

🧠 Arquitectura del sistema

El proyecto fue desarrollado aplicando principios de Programación Orientada a Objetos (POO), utilizando clases como:

  • Producto: Representa cada libro almacenado en el sistema.
  • Inventario: Gestiona la colección de productos utilizando listas y diccionarios.

También se implementa persistencia de datos utilizando distintos formatos de archivo como:

  • 📄 Archivos TXT
  • 📊 Archivos CSV
  • 🗂 Archivos JSON

⚙ Tecnologías utilizadas

  • 🐍 Python
  • 🌐 Flask Framework
  • 🗄 SQLite Database
  • 🧩 Jinja2 (Plantillas)
  • 🧱 HTML5
  • 🎨 CSS3 y Bootstrap 5

Proyecto desarrollado como práctica académica en la asignatura Desarrollo de Aplicaciones Web de la Universidad Estatal Amazónica.
